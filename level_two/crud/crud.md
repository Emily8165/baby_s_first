# CRUD
Crud stands for Create, Read, Update, Delete
Create a small program that allows a user to create, read, update, and delete lines from a file.

## Problem Statement 
-

## Requirements 
I should be able to:
1. Add a new line to a file
2. Read all lines from a file
3. Update a line from a file
4. Delete a line from a file

## Assumptions 
file type does not matter (txt or csv is preferred)

## Example 
>>> python level_two/crud/crud.py
. Welcome to crud
. please select create, read, update or delete.
>>> create
>>> "this is my data"
. line 1: "this is my data" saved!
>>> read
. line 1: "this is my data"
>>> update
>>> 1, "this is my new data"
. line 1: "this is my new data"
>>> delete
>>> 1
. line 1: deleted!
