# Welcome to Baby's first repo

## Quick start
Assuming you are learning python (which might not be the case) run the setup.sh file using the following:
`chmod +x setup.sh && ./setup.sh`

In the case you are not feel free to disregard. 

## Quick tour PLEASE READ
This repo is broken out into three sections: 
1. startup

    This is the knowledge base of the repo and itself is split into two parts. 

    * The first being computer_science which is where all the knowledge I have tried to collect for eductional purposes is being held. Itself is group into modules for ease of understanding. 
    * The second is enterprise and contains information about tools you will use as a developer. The tools mentioned are not optional. You will use them and you will need them, please look at enterprise and follow the `getting_started_readme.md`

2. Challenges

    The challenges folder is a series of [leetcode](www.leetcode.com) styles problems that are written in a way to mimic real life requests and tickets. Context is given for the project and you are then expected to implement the solution. 

3. Projects

    These are some ideas for bigger projects that you can do in order to gain real world experiance and develop a portfolio of work. This is currently not written yet but is being worked on. 


## Why use this repo
The goal of this repo is to give you some challenges to help you with learning a new programming language. 
It is recommended that you stick to one programming language per repo clone. If you want to start on a new language, 
clone a fresh copy of this repo and you can add them. 

There is a setup.sh file for python users which will get an enviroment set up for you so that you don't accidently add
any packages at root. 

## Rules
1. This repo is free to use and distribute.
2. Try not to use AI. Work on the problems yourselves and if you are stuck as AI for help. Please no copy and paste, you will not learn that way. If you do use AI for help, leave a comment saying where it helped you and why you were stuck.
