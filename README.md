# Welcome to Baby's first repo!

## Why use this repo!
The goal of this repo is to give you some challenges to help you with learning a new programming language. 
It is recommended that you stick to one programming language per repo clone. If you want to start on a new language, 
clone a fresh copy of this repo and you can add them. 

There is a setup.sh file for python users which will get an enviroment set up for you so that you don't accidently add
any packages at root. 

## Rules:
1. This repo is free to use and distribute.
2. Try not to use AI. Work on the problems yourselves and if you are stuck as AI for help. Please no copy and paste, you will not learn that way. If you do use AI for help, leave a comment saying where it helped you and why you were stuck. 

## Github workflow:
Have a look at a challenge directory. 
read the challenge in the directory. 

If you want to do the challenge, check out a new git branch (git checkout -b <branch_name>)
add the changes to the branch (git add <file>)
commit the changes (git commit -m "<message>")

From here you have two options:

Option a: if you are working locally
1. go back to main (git checkout main)
2. merge the change you have made into your main branch (git merge <branch_name>)

Option b: if you are working with github:
1. push your changes to github (git push --set-upstream origin <branch_name>)
2. go to github and follow commands
3. go back to your terminal
4. go to main (git checkout main)
5. git pull

once you have done this you changes will appear on your main branch. 

It is then best practice to clean up the branch by deleting it (git branch -d <branch_name>)
