# Mad Libs Game Challenge

Create an interactive Mad Libs word game that asks the user for input and completes sentences based on their responses.

## Instructions
1. Prompt the user to start playing the game.
2. Ask the user sequentially for three specific types of words:
   * A **noun**
   * A **verb**
   * An **adjective**
3. Output the final completed sentence using the user's inputs.

## Example Output

```text
Lets play madlibs!
Give me three words to add into a sentence!
first give me a noun
>>> "dog"
next give me a verb
>>> "running"
finally give me an adjective
>>> "funny"
The dog was running funny
```

2. order of operations
