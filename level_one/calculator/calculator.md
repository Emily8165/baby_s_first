# Basic Calculator Challenge

Create a basic calculator program where a user is prompted to submit an equation, and the program prints the computed answer to the screen.

## Requirements
1. **Basic Operations:** The calculator must support addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
2. **Number Types:** The program must handle and return both integer and floating-point numbers depending on the result.
3. **Negative Numbers:** The calculator must support operations involving negative numbers.

## Assumptions
* Inputs will consist of standard 32-bit numbers.

## Example Usage

### Example 1
```text
Give me an operation!
>>> 2+2
2+2=4
```
## Learning Objectives
1. string to int type convertion
2. working with command line arguments
3. logic statements / match cases
4. operators
