# Contact Challenge

## Problem statement
I have alot of friends and I struggle to keep track of their gamer tags! I need you to build me a program that helps me keep track of them and lets me easily recall them. I'm only worried about 5 gamers for now but I want to be able to type their names into the terminal and then get their gamer tags back. Here are the gamers:

Alex - "coolGuy69"
Gerda - "xxsniper_coolxx"
Emily - "GoofBall420"
Belle - "OhMyGod126"
Amy - "SleepyGorl321"

## Example
>>> python level_one/contacts/contacts.py alex
. coolGuy69
>>> python level_one/contacts/contacts.py Gerda
. xxsniper_coolxx

## Requirements
1. Inputted name can either be capitalized or lower case but still returns the gamer tag
2. The correct gamer tag is returned 
3. A name that is entered but is not in the list will say `"not found in gamer files"`

## Learning Objectives
1. working with command line arguments
2. working with hashmaps / dictionaries
