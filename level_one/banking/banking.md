# Banking

## Problem Statement 
I need to keep track of my money better! I want you to build me a basic program to help me keep track of my cash!
Create a small program that keeps track of how much money I have whilst the program is running. 

## Requirements 
When the program starts running make me have a balance of 1000 then if I spend money it goes down by that amount, if I deposit some money then it goes up by that amount. 

1. The program allows me to deposit or spend money.
2. The program prints my balance whenever I deposit or spend money. 
3. The program continues running until the user exists the program.
4. Ensure that any deposit or withdrawl is serialized correctly (not string input)
