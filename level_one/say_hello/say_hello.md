# Say Hello! - Easy

Welcome to your first Python challenge! The goal of this challenge is to introduce you to fundamental programming concepts:

1. **Printing to the terminal**
2. **Order of operations** (the sequence in which instructions are executed)
3. **Escape codes**, new line separators (`\n`), and tab indentors (`\t`)

---

## Task 1: Basic Hello World

Write a script that prints the string `"hello world"` to the terminal.


## Task 2: Working with new lines

Write a script that prints the string `"hello world"` to the terminal by with each word on a new line like this:
`hello`
`world`


## Task 3: Working with new lines

Write a script that prints the string `"hello world"` to the terminal by with each word on a new line and with world
tabbed forward like so:
`hello`
`   world`
