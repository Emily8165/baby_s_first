# Getting started
There are three tools you will use as a developer especially when getting started. These are:
1. git / version control

    This is what is use to save your work and share it with others. Right now you are looking at a github repo, so you will need to learn how to use it. Look at the `github_explained` folder to understand the basics

2. Intergrated Development Enviroment (IDE)

    This is what we use to write and also run code on. Every developer needs and IDE for ease of learning and development. You may not have an IDE by default so if you don't have one look at the IDE folder to get vscode.

3. Terminal

    This is an application used to control your machine. It runs your code, allows your to interact with git and is very important to development. You will have one already installed by default on your workstation. Look at the folder to see how to access it.
