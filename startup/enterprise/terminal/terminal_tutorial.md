# Terminal
A terminal or command line interface (CLI) is a device or interface developers use to control their computer's systems. 
In this repo will will define a terminal input with '>>>'

## Where to find the terminal
MACOS - You can find your terminal by hitting CMD then space bar, and then typing in terminal.
LINUX - You can find your terminal by hitting Ctrl + Alt + T when you are looking at your home screen.
WINDOW - You can find your terminal by hitting Ctrl + Shift + P, and searching for windows terminal in the search pallet (or you could help yourself by just installing linux instead)

## How to use the terminal
You will just need to type a command into the terminal line and then hit enter. For example to print the string "hello world" in your terminal: 
>>> echo "Hello World"
